# Automatic Street Light System using Arduino and LDR

## Project Description

This project implements an automatic street light system using an Arduino and LDR sensor. The LDR detects the surrounding light intensity and the Arduino controls an LED according to the detected condition.

## Objective

To develop and test an automatic street light system and use GitHub for QA documentation, issue tracking and problem solving.

## Components Used

- Arduino Uno
- LDR
- 10kΩ resistor
- LED
- 220Ω resistor

## Working

The LDR senses the surrounding light intensity. When the detected light level represents a low-light condition, the Arduino switches the LED ON. When sufficient light is detected, the LED is switched OFF.

## Software Used

- Arduino IDE
- Wokwi
- GitHub

## QA Approach

The project is tested for sensor response, LED operation and threshold behavior. Identified problems are documented using GitHub Issues. Root causes are analyzed and corrective actions are recorded using project documentation.
